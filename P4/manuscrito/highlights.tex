\section*{Highlights}
\begin{itemize}
\item HD 166620 varies less in its grand minimum than in cycle minimum 2 (not clearly 1)
\item No segment shows a consistent rise in rolling autocorrelation or variance
\item The surrogate test has nominal size but little power, and none with a cycle added
\item A model of cycle loss moves both indicators down, not up as assumed
\item The HD 166620 record ends before its transition, so H2 was not testable
\end{itemize}
