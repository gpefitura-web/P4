# Exemplos

`exemplos/p1/` guarda artefatos reais do P1 (flares estelares, EPL) como **referência de formato**, não como regra:
- `DECISIONS_P1.md`: decisões congeladas (mistura processo e física; as de processo foram para `docs/REGRAS_PROCESSO.md`).
- `PAPER_STATE_P1.md`: estado completo de um paper (pergunta, método, orçamento de páginas, riscos, mensagem, "o que não afirma", plano de redação).
- `PROMPT_PROXIMO_CHAT_P1.md`: prompt de abertura e checklist de retomada.
- `CADERNO_exemplos.md`: duas entradas de artigo e uma de log.
- `refs_list.yml`: lista real de 46 referências com `fonte`, `bibcode`, `validacao_visual` e papéis.
- `main_P1.tex`: manuscrito com resumo real (para ver o uso de macros).
Valores, bibkeys e decisões daqui **não** valem para outros papers.
